=====================================
  NextCV - Guia de Configuracao
=====================================

Este guia explica como configurar todos os servicos necessarios para rodar a plataforma NextCV.


==========================================
  1. GEMINI API (Google AI)
==========================================

1.1. Criar Projeto no Google Cloud
  - Acesse: https://console.cloud.google.com/
  - Clique em "Criar Projeto"
  - De um nome ao projeto (ex: "nextcv-prod")
  - Clique em "Criar"

1.2. Gerar Chave API do Gemini
  - Acesse: https://aistudio.google.com/apikey
  - Faca login com sua conta Google
  - Clique em "Create API Key"
  - Selecione o projeto criado
  - Copie a chave gerada

1.3. Configurar no Next.js
  - Abra o arquivo .env.local na raiz do projeto
  - Adicione:
    GEMINI_API_KEY=sua_chave_api_aqui

  IMPORTANTE: Esta variavel NAO tem o prefixo NEXT_PUBLIC_ pois e usada
  apenas no servidor (API Routes).


==========================================
  2. FIREBASE
==========================================

2.1. Criar Projeto Firebase
  - Acesse: https://console.firebase.google.com/
  - Clique em "Adicionar projeto"
  - De um nome (ex: "nextcv")
  - Pode desabilitar Google Analytics (opcional)
  - Clique em "Criar Projeto"

2.2. Registrar App Web
  - No painel do projeto, clique no icone "</>" (Web)
  - De um apelido (ex: "nextcv-web")
  - NAO marque Firebase Hosting (usaremos Vercel)
  - Clique em "Registrar app"
  - Copie as configuracoes exibidas (apiKey, authDomain, etc.)

2.3. Configurar Firebase Auth
  - No menu lateral, va em "Authentication"
  - Clique em "Comecar"
  - Na aba "Metodo de login", habilite:
    * Email/Senha
    * Google
  - Para o Google, adicione seu email como suporte
  - Salve as configuracoes

2.4. Configurar Firestore
  - No menu lateral, va em "Firestore Database"
  - Clique em "Criar banco de dados"
  - Escolha "Iniciar no modo de teste" (para desenvolvimento)
  - Selecione a regiao mais proxima (ex: southamerica-east1)
  - Clique em "Criar"

  Regras de seguranca recomendadas para producao:

  rules_version = '2';
  service cloud.firestore {
    match /databases/{database}/documents {
      match /users/{userId} {
        allow read, write: if request.auth != null && request.auth.uid == userId;

        match /transactions/{transactionId} {
          allow read: if request.auth != null && request.auth.uid == userId;
          allow write: if false; // Apenas pelo servidor
        }
      }

      match /resumes/{resumeId} {
        allow read, write: if request.auth != null && request.auth.uid == resource.data.userId;
      }

      match /roadmaps/{roadmapId} {
        allow read, write: if request.auth != null && request.auth.uid == resource.data.userId;
      }
    }
  }

2.5. Configurar Storage
  - No menu lateral, va em "Storage"
  - Clique em "Comecar"
  - Escolha "Iniciar no modo de teste"
  - Selecione a mesma regiao do Firestore
  - Clique em "Concluir"

  Regras de seguranca recomendadas para producao:

  rules_version = '2';
  service firebase.storage {
    match /b/{bucket}/o {
      match /resumes/{userId}/{allPaths=**} {
        allow read, write: if request.auth != null && request.auth.uid == userId;
      }
    }
  }

2.6. Configurar no Next.js
  - Abra o arquivo .env.local na raiz do projeto
  - Adicione todas as variaveis do Firebase:

    NEXT_PUBLIC_FIREBASE_API_KEY=sua_api_key
    NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=seu_projeto.firebaseapp.com
    NEXT_PUBLIC_FIREBASE_PROJECT_ID=seu_project_id
    NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=seu_projeto.appspot.com
    NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=seu_sender_id
    NEXT_PUBLIC_FIREBASE_APP_ID=seu_app_id


==========================================
  3. DEPLOY NA VERCEL
==========================================

3.1. Preparar o projeto
  - Certifique-se de que .env.local esta no .gitignore
  - Faca push do codigo para um repositorio Git

3.2. Deploy
  - Acesse: https://vercel.com/
  - Importe o repositorio
  - Configure as variaveis de ambiente:
    * Todas as variaveis NEXT_PUBLIC_FIREBASE_*
    * GEMINI_API_KEY
  - Clique em "Deploy"

3.3. Configurar dominio (opcional)
  - Nas configuracoes do projeto na Vercel
  - Adicione seu dominio personalizado


==========================================
  4. ABACATE PAY (Futuro)
==========================================

  Quando a integracao de pagamento for implementada:

  - Acesse: https://abacatepay.com/
  - Crie uma conta
  - Gere as chaves de API
  - Configure as variaveis:
    ABACATE_PAY_API_KEY=sua_chave
    ABACATE_PAY_WEBHOOK_SECRET=seu_webhook_secret
  - Configure o webhook URL na plataforma:
    https://seu-dominio.com/api/webhooks/payment


==========================================
  5. EXECUTAR LOCALMENTE
==========================================

  # Instalar dependencias
  npm install

  # Copiar e configurar variaveis de ambiente
  cp .env.local.example .env.local
  # Edite .env.local com suas chaves

  # Rodar em desenvolvimento
  npm run dev

  # Acessar
  http://localhost:3000

  # Build de producao
  npm run build
  npm start
